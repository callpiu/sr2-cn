# v548：修复退出游戏和部分 Esc 操作卡住

2026-10-25 用户在 Steam 卸载重装后覆盖旧整合包，发现主界面退出游戏、部分 Esc 操作卡住。对照用户提供的正常运行备份，问题来自整合包漏带 SuperUI 配套文件。

## 根因

历史构建脚本 `archive/legacy-tools/build_full_v546.py` 从当前游戏目录仅挑选 `Mods/dialog_box.lua` 和 `Mods/city_load.lua`。这两个文件来自 SuperUI 2.9，但公共库和其他组件未加入发行包。已有完整 SuperUI 的旧游戏目录能运行；干净游戏目录只剩不完整的覆盖层。

Juiced 日志确认实际加载 `mods\dialog_box.lua`。它在 `dialog_box_open_internal` 第 362 行直接调用 `sui_compare_string`。旧整合包没有 `Mods/vint_lib.lua`，汉化 VPP 中的原版库也没有这个函数。确认框创建因此在显示选项前中断，表现为退出、设置退出提示等操作后界面无法继续。暂停相关路径还使用 `sui_is_zombie` 等同库函数。

正常备份与故障目录的以下三项 SHA-256 均一致：

| 文件 | SHA-256 |
| --- | --- |
| SR2_pc.exe | `8bfc0c2a3606861837d8d831c5cdc1535db7d45813c809c04251018b5d4eecf7` |
| DFEngine.dll | `263ec33e6dad4f3a46ed8f24726f10e5fbba44206d95e17f6aa3019eb696d7c8` |
| patch.vpp_pc | `e125d83628f8552035efc47e07778054ca593a718ba87570df03caa7a524d76b` |

这次不修改直升机字幕的 16 字节补丁，也不更换 Juiced DLL 或汉化文本包。

## 修复范围

按原始 `SuperUI_vanilla.7z` 的组件清单，从正常运行备份恢复缺失的 64 个文件。加上原有两个定制脚本，完整组件为 66 个文件，包括公共库、菜单/HUD 脚本、任务脚本和配套表资源。保留正常备份里已有的中文定制，不重新翻译。

原始 SuperUI 的 loose `static_CH.le_strings` 不在正常运行备份中，不加入本包；继续使用本项目 `patch.vpp_pc` 中已验证的简中 slot 文本表。备份中的 ReShade、dgVoodoo、DLSS 组件、日志、崩溃转储、历史备份和重复 Mods 目录不属于此次 SuperUI 依赖修复。

组件清单与每文件哈希见 `localization/superui-manifest.json`。作者为 nclok1405，保留原文件作者标注。

## 验证

1. 用 Lua 5.1 执行实际发布的对话框脚本，并模拟引擎接口：使用原版库时，退出确认、设置退出提示和联机等待提示三项均在 `sui_compare_string` 未定义处失败；换成正常备份的公共库后三项均完成。该测试验证 Lua 控制流，不替代游戏渲染或原生回调检查。
2. 只补一个 `Mods/vint_lib.lua` 的单变量实机验证：用户确认“退出和 Esc 都正常”。
3. 补齐全部组件、重启游戏后，用户再次确认“全部正常，已退出游戏”，对应主菜单显示、Esc 返回和退出游戏。
4. `tools/verify_superui.py` 在旧 v547 发布目录发现 64 个缺项；在 v548 载荷及当前游戏目录通过，66 个文件哈希一致，11 个 SuperUI 函数调用均有定义。此检查已加入项目 CI。

实机结果来源为用户反馈；窗口采集工具两次超时，无新增截图。此前直升机护卫 2～6 级验证记录独立保留。

## 升级

退出游戏后，将 v548 完整包覆盖到游戏根目录。已有正确直升机字幕修复时，安装器会识别为已安装。完整包仍采用覆盖复制，安装前保留自己的文件备份；管理器只负责新增字幕修复的安装和回退。

## 帮助菜单名称

主菜单帮助中的“是阿困呀汉化”来自 `MAINMENU_CREDITS` 的定制翻译。两个菜单脚本保留字符串 `label` 字段，按相邻 Profile/Settings/SuperUI 项目的方式直接显示原版英文 `Credits`，继续调用原来的制作人员名单页面；不改动公共文本包。

先前试用数字 `label_crc` 替代 `label` 的版本虽通过 Lua 语法检查，但实机启动卡在读取 100%，主菜单文字缺失。回退两个脚本后用户确认启动恢复正常。该方案未发布；最终字符串标签版本经用户重启实测，确认“主菜单正常，Credits 显示且能打开”。

## 本次修正

旧包只附带 SuperUI 的两个定制脚本，却漏带公共库和其他配套文件。v548 从已正常运行的备份补齐 64 个遗漏文件，保留原有简中、Juiced 和 DLC 内容。退出、Esc 的卡住来自缺失 Lua 函数，与直升机字幕的 16 字节 EXE 修复无关。

## 安装步骤

1. 正常退出游戏。已有游戏请先保留自己的原文件备份，尤其是自定义 `juiced.ini` 和 `Mods`。
2. 在 Steam 库中右键《黑道圣徒2》，打开“属性 → 通用 → 启动选项”，添加：

   ```text
   forcelang_ch
   ```

3. 完整解压，将本包内全部文件和文件夹复制到《黑道圣徒2》游戏根目录（包含 `SR2_pc.exe` 的目录），覆盖同名文件。整合包已经包含 Juiced Patch，不需要另外安装。
4. 直接双击游戏根目录中的 `SR2_pc.exe` 运行一次，让包内 Juiced Patch 完成首次安装和初始化；进入游戏后再正常退出。
5. 双击游戏目录中的 **一键安装汉化.cmd**，也可使用 **启动中文补丁管理器.cmd**。看到安装成功后，再通过 Steam 正常启动游戏。
6. 之后继续保留 `forcelang_ch` 启动参数。

覆盖安装沿用整合包方式；图形管理器和自动回退只管理字幕修复，不负责回滚整个 Juiced、DLC 与汉化整合包。

## 新增修复的使用方式

- **启动中文补丁管理器.cmd**：选择目录、安装、检查、卸载字幕修复。
- **检查修复状态.cmd**：校验主程序和汉化资源是否匹配、修复是否已安装。
- **卸载字幕修复.cmd**：恢复安装器备份的原程序，汉化、Juiced 和 DLC 保持当前状态。
- 字幕修复原程序备份位于游戏目录 `.sr2-heli-subtitle-fix/original.exe`。不要在需要回退前删除它。

除本项目明确列出的汉化与修正载荷外，其余原包资源、Juiced、DLC 文件按原始字节保留。v552 的 `juiced.ini` 已替换为 Juiced 9.3.2 默认配置；已有自定义设置的玩家请先备份并自行合并，避免覆盖个人选项。

## v553 DLC 任务重玩报纸修复

- 修正据点重玩报纸板「额外内容」中的六个 DLC 任务只显示通用剪报、详情隐藏大图的问题。

- 修复后进入「额外内容」时加载原 DLC 图集 `ui_crib_news_dlc`，六个任务各自显示专属缩略图、详情大图，并读取现有简中 `*_HEADLINE_TEXT` 报道；离开该页时卸载。
- 序章及本体任务的剪报、未解锁任务与自定义任务的默认剪报逻辑保持不变。
- 只替换 `Mods/mission_replay.lua`，不改存档、原生文本表、DLC 资源和 EXE；报纸图片内的英文贴图保持原样。
- 第一版曾误用 Lua 5.1 的 `string.match`，游戏内置 Lua 5.0 会中断菜单初始化；v553 改用任务 ID 查表，不再依赖字符串库。

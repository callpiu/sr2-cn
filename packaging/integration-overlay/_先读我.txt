# 黑道圣徒2 简体中文 + Juiced 9.3.1 + DLC 1.0.1 整合包 v549

更新日期：2026-10-25。修正帮助菜单、Juiced 选项漏译、错译和缺字，补齐 Sandbox++ 帮助。保留完整 SuperUI 2.9 与直升机护卫字幕修复。

## 本次修正

旧包只附带 SuperUI 的两个定制脚本，却漏带公共库和其他配套文件。v548 从已正常运行的备份补齐 64 个遗漏文件，保留原有简中、Juiced 和 DLC 内容。退出、Esc 的卡住来自缺失 Lua 函数，与直升机字幕的 16 字节 EXE 修复无关。

## 安装步骤

1. 正常退出游戏。已有游戏请先保留自己的原文件备份，尤其是自定义 `juiced.ini` 和 Mods。
2. 完整解压，将本包内全部文件和文件夹复制到《黑道圣徒2》游戏根目录（包含 `SR2_pc.exe` 的目录），覆盖同名文件。这一步安装原整合包的简中、Juiced 和 DLC 内容。
3. 在游戏目录中双击 **一键安装修复.cmd**。看到“修复安装成功”或“修复已安装”后，再启动游戏。这一步应用新字幕修复，不能省略。
4. 按你原来的方式启动游戏，原有中文启动参数请保留。直升机护卫活动2级的两句提示已实测，并确认重启后正常；2026-10-24 用户补充确认2～6级已逐级实机验证通过。

步骤2沿用原包的覆盖安装方式；本包的图形管理器和自动回退仅管理步骤3的字幕修复，不负责回滚整个 Juice/DLC/汉化整合包。

## 新增修复的使用方式

- **启动中文补丁管理器.cmd**：选择目录、安装、检查、卸载字幕修复。
- **检查修复状态.cmd**：校验主程序和汉化资源是否匹配、修复是否已安装。
- **卸载字幕修复.cmd**：恢复安装器备份的原程序，汉化、Juiced 和 DLC 保持当前状态。
- 字幕修复原程序备份位于游戏目录 `.sr2-heli-subtitle-fix/original.exe`。不要在需要回退前删除它。

除本项目明确列出的汉化与修正载荷外，其余原包资源、Juiced、DLC 文件按原始字节保留；没有用本机当前设置覆盖包内设置。`juiced.ini` 仍为原包版本，已有自定义设置的玩家请自行合并，避免直接丢失配置。

## 兼容范围

字幕修复只支持本次已验证的同版 `SR2_pc.exe` 和包内简中资源。安装器会校验完整 SHA-256，不支持的主程序会停止修改。不能保证 GOG、其他破解/修改主程序或原繁中版本兼容；不能将“可复制原整合资源”等同于“字幕修复支持任意 EXE”。

本包含 SuperUI 2.9 配套脚本和表资源，原作者为 nclok1405。

本包不含游戏本体或 `SR2_pc.exe`。需要已有可运行的游戏。修复使用 Windows 自带 PowerShell，不需要 Python 或联网。

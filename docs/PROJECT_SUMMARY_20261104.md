## 1. 项目目标

本项目为《Saints Row 2》制作可部署、可校验、可复现的简体中文整合补丁，重点解决以下问题：

- 提供本体简体中文、字体、字符表和 DLC 1.0.1 中文文本。
- 适配 Juiced Patch 9.3.2 的中文菜单与文本加载方式。
- 修复原版繁中遗留、并在简中化后继续出现的直升机护卫活动字幕乱码。
- 补齐 SuperUI 2.9 配套组件，避免主菜单、Esc 返回和退出确认等位置卡住。
- 修复菜单漏译、错译、缺字、统计与成就显示异常。
- 提供安全、可回退的直升机字幕修复安装器。
- 保留原始资源和第三方许可，并记录自动验证与实机验证结果。

## 4. 已完成的功能

### 4.1 本体与 DLC 汉化

- 简体中文文本、字体和字符表资源已冻结在可部署载荷中。
- DLC 1.0.1 的 982 条 slot 编码中文文本已纳入整合包。
- 当前文本导出共 17,631 条资源记录、2,795 项字符表记录。
- 导出的 JSON 用于审阅和自动验证，实际安装以 `localization/payload` 中的二进制载荷为准。

### 4.2 Juiced Patch 适配

- 升级到 Juiced 9.3.2 的 DLL、鼠标 UI 与默认配置。
- 保留并修正 Juiced 菜单中的漏译、错译和缺字。
- 修正 OpenSpy 联机界面的 12 条中文文本及“等待玩家”等 SUI 标签。
- 保留格式标签、输入图标、指令编号、网址和按键图标。
- 当前 `juiced_CH.cxt` 共 412 条有效条目：406 条既有项目文本加 6 条 9.3.2 硬编码修正。

### 4.3 帮助菜单与 Sandbox++

- 主菜单“帮助”中的四个入口已显示为中文并可正常打开。
- 补齐 Sandbox++ 14 页标题和说明。
- 保留 493 条指令编号及其顺序。
- 菜单文本、脚本、字体和设置均已通过静态检查，并由用户重启后实机确认。

### 4.4 SuperUI 2.9 完整性修复

旧版整合包只包含两个 SuperUI 定制脚本，缺少公共库和配套组件。在全新游戏目录中，这会导致：

- 主界面“退出游戏”后无法显示确认框。
- 部分 Esc 操作卡住。
- 菜单依赖函数缺失。

v548 从已正常运行的备份补回 64 个文件。用户完整重启后确认主菜单、Esc 返回和退出游戏恢复正常。

### 4.5 直升机护卫活动字幕乱码

问题来源不是字体或普通字符串表，而是原版中文分支中的两处硬编码文本返回逻辑。Juiced Patch 已把这些文本识别为硬编码项，但旧版补丁仍会绕过正常 CXT 查表路径。

本项目采用两层修复：

1. 对支持版本 `SR2_pc.exe` 做 16 字节最小修改，让直升机护卫活动文本回到正常字符串表查询。
2. 向 Juiced 作者提供包含六条中文文本的 `juiced_CH.hardcoded-fixes.cxt`，供上游移除硬编码分支后直接合并。

安装器会校验原程序和文本资源哈希，支持安装、检查、卸载和恢复。用户已逐级实机确认直升机护卫 **2～6 级**字幕正常；1 级原本正常。

### 4.6 名单、提示与信息页

- 汉化 30 个杀手目标及说明。
- 汉化 40 辆拆车厂目标及说明。

### 4.7 v551 文本补全

## 7. 安装方式

1. 正常退出游戏并备份原有文件，尤其是自定义 `juiced.ini` 和 `Mods`。
2. 在 Steam 启动选项中添加：

```text
forcelang_ch
```

3. 解压完整整合包，将全部文件和文件夹复制到包含 `SR2_pc.exe` 的游戏根目录，覆盖同名文件。整合包已经包含 Juiced Patch。
4. 双击一次游戏根目录中的 `SR2_pc.exe`，让 Juiced 完成首次安装和初始化，然后正常退出。
5. 运行“一键安装汉化.cmd”或“启动中文补丁管理器.cmd”。
6. 确认安装成功后，通过 Steam 正常启动游戏。

图形管理器只负责直升机字幕修复的安装、检查与卸载；整个整合包仍采用覆盖安装。若要回滚整个整合包，应使用安装前的个人备份。

## 10. 已知限制

- 字幕修复只支持已记录的 Steam App 9480 / Build 1076239 主程序及配套文本。
- 不保证兼容 GOG、其他破解版本、修改过的主程序或其他汉化包。
- 拆车厂杂志封面的英文属于贴图，当前仍保持原样。
- 45 条载入提示为代表性实机抽查，并未逐条进入所有触发场景查看。
- 27/27 竞速完成标记通过实际 Lua 回调边界测试，尚无真实满额存档的完成星实机截图。
- 部分字体缺少的字位采用同义改写绕行；这不等同于所有游戏界面均已完整校对。
- 运行 Steam“验证游戏文件完整性”可能恢复被覆盖的资源，需要重新安装补丁。
- 安装或更新其他 Juiced、SuperUI 或汉化包可能覆盖本项目的定制文件。
- v552 新增过场字幕的完整重启回放确认仍待记录；Juiced 9.3.2 的菜单、联机、超宽屏提示和动画回归也应继续观察。

## 11. 维护建议

- 修改文本时先更新 `localization/text` 下的规范源，再运行对应构建脚本。
- 不要直接编辑已构建的 CXT、Lua 或 VPP 文件来替代源文件维护。
- 每次改包后同时核对载荷、安装器清单、`FILELIST.txt`、ZIP 哈希和独立重建结果。
- 涉及游戏运行的修复必须记录“源文件、包、已安装、运行中”四个状态，避免仅凭静态哈希宣称实机正常。
- 新增或替换资源时检查第三方许可和再分发范围。
- 发布前等待 GitHub Actions 完成，并在 Release 草稿中逐项核对上传文件的大小和 SHA-256。

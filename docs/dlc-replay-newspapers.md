# DLC 任务重玩报纸

在 v552 的据点重玩报纸板中，「额外内容」可以列出 DLC 任务，但六个已完成的任务会使用通用剪报。详情也会隐藏专属剪报并显示无报道提示。

Juiced 先查找 `Mods` 中的同名脚本，再查找 `DLC`。整合包使用的 SuperUI `Mods/mission_replay.lua` 只给本体任务分配专属图片，并用 `ui_crib_news_em` 绘制「额外内容」。原 DLC 的 `DLC/UI/mission_replay.lua` 则会加载 `ui_crib_news_dlc`。对照 DLC 1.0.1 原包，安装目录中的脚本、位图表和七组 PEG 文件均与原包一致。

修复保留 SuperUI 脚本，仅对 `dlc01` 至 `dlc06` 加载原 DLC 缩略图、大图和现有简中报道。进入「额外内容」时先加载 DLC 缩略图集，离开该页时卸载；本体的 `em01`、未解锁任务和自定义任务仍使用原分支。此修正不翻译报纸图片内的英文。

第一版补丁调用了 Lua 5.1 新增的 `string.match`，而游戏程序内置 Lua 5.0。该调用在序章处理已解锁任务时就会执行，导致初始化中断；实机现象为章节文字重叠且 Shift 无法切换。第二版改用六个任务 ID 的查表，不再依赖字符串匹配库。

禁用 `string.match` 的 Lua 回归复现了第一版的初始化错误。第二版通过序章剪报、切入及退出额外内容、六组缩略图和详情大图，以及自定义任务和未解锁任务的默认剪报检查。六个报道键均存在于简中 DLC 文本表。

2026-11-05，用户重启 Steam 简中整合版后确认：章节文字排列正常，Shift 可切到「额外内容」，DLC 报纸缩略图和详情显示正常。实机结果来自用户对同一菜单的复测；六组任务的逐项覆盖由上述 Lua 回归验证。

本地修复可覆盖 v552 的 `Mods/mission_replay.lua`，恢复该文件的原版备份即可撤回。已发布的 v552 ZIP 和校验值保持原样；精确重建旧 ZIP 时使用 `v552-20261104` 标签。

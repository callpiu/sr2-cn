## 实现与复建

唯一安装改动为 `Mods/JUICED - Strings/juiced_CH.cxt`。不修改原有 Lua、NPC/车辆标识、载具变体、存档或游戏程序。此前的 98 条菜单与帮助记录完整保留。

译文与来源记录：`localization/text/list-tips.json`。人名沿用现有中文说明；车型在列表和说明中使用一致的译法。保留实际拨号号码 `555-FIRE`、`555-OOPS` 和引擎规格 `V8`。当前字体为有限槽位字库，译名采用其已有字形。

多段说明使用 Juiced 原生 CXT 的 `"TAG" text\n\ntext` 行内格式；段落换行与控制序列完整保留。普通单行名称和提示使用 `[TAG]` 节格式。文件为 UTF-8、无 BOM、CRLF。

从仓库目录运行：

```powershell
python tools/build_list_tips.py
python tools/verify_project.py
```

构建可重复运行，结果一致。构建器仅替换其负责的记录，保留其他 CXT 条目，并更新安装清单中的长度和哈希。

载入提示中原先涉及固定键位、武器升级、双筒望远镜等不符合当前游戏功能的内容，改为本作适用的操作与玩法提示。其余内容保留原意，使用简短中文，避免在载入画面溢出。

# 黑道圣徒2：直升机护卫字幕修复补丁 v1.0.0

这是已通过游戏重启实测的两句活动提示修复。适用于 Windows 10/11，不需要 Python、编译器或联网。

## 怎么用

1. 正常退出《黑道圣徒2》。完整解压本压缩包，不要直接在压缩软件里运行。
2. 双击 **一键安装修复.cmd**。安装器会查找 Steam 游戏目录；找不到或存在多份时，选择含 `SR2_pc.exe` 的文件夹。
3. 看到“修复安装成功”后重新启动游戏，进入直升机护卫活动验证。

也可双击 **启动中文补丁管理器.cmd**，在同一窗口选择目录、安装、检查或卸载。

## 支持的版本

- 本次验证环境：Steam App 9480 / Build 1076239，同版主程序与简中 v546 文本资源（v545 共用这份文本包）。Juiced 9.3.1 已实测。
- 安装器严格校验主程序和 `patch.vpp_pc` 的完整 SHA-256。不匹配时停止，不会尝试通用偏移或强行修改。
- 原版繁中、其他汉化包、不同 EXE 和修改过的主程序不属于本包的已验证兼容范围。
- 这是一份字幕修复补丁，不包含完整简体汉化、Juiced、DLC、字体或游戏程序。对方需要先装好匹配的游戏和简中资源。
- 字幕在本机2级已确认修复，重启后仍正常；2026-10-24 用户补充确认2～6级已逐级实机验证通过。

版本不匹配时，请保留提示中的校验值；不要关闭校验后强行安装。

## 备份与卸载

安装前自动将原程序保存到游戏目录的 `.sr2-heli-subtitle-fix/original.exe`。

双击 **卸载字幕修复.cmd** 或在管理器中选择“卸载 / 恢复”，恢复经校验的原程序。卸载不会删除备份，也不会改动存档、汉化资源或 Juiced。

如需手动回退，先退出游戏，将上述 `original.exe` 复制为游戏目录中的 `SR2_pc.exe`。仅在备份 SHA-256 与下方原始值一致时使用。

已经由其他方式修好的同版主程序会显示“已安装”。若本安装器未保存备份，会明确提示，自动卸载不会冒险还原未知文件。

## 故障处理

- 游戏正在运行：先退出，再运行安装器。
- 路径含目录联接或符号链接：选择真实安装目录。
- 无写入权限：把补丁解压到自己可写的目录，再确认游戏目录权限；安装器不会自动提权。
- 安装意外中断：不要删除 `.sr2-heli-subtitle-fix`，重开安装器或运行“检查修复状态”即可核对并恢复事务记录。
- 检查状态只验证文件，不能代替游戏内验证。安装后请完整重启游戏。

安装、检查、卸载的 PowerShell 入口分别是 `Install.ps1`、`Test-Patch.ps1`、`Uninstall.ps1`，支持 `-GameDirectory "游戏目录"` 参数。`一键安装汉化.cmd` 为同功能安装入口，本包仅修复字幕。

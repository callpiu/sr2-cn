## 四 · 三条可行路线（按推荐度）

### 路线 1（最推荐）：**内存搜索** —— 唯一能一锤定音的方法

既然乱码字**不存在于磁盘**，它一定在**内存里**。

```
工具：Cheat Engine
步骤：
  1. 启动游戏，进入直升机突击活动，让字幕出现
  2. Cheat Engine 附加到 SR2_pc.exe
  3. 搜索字符串「任璨」（UTF-16，即 hex: FB 4E A8 74）
       - 若要搜宽字符：勾选 "Wide string" 或手动用 Array of byte 搜 FB 4E A8 74
  4. 找到地址后，右键 → "Find out what accesses this address"
       -> 即可看到是哪个模块/资源在读它
  5. 若地址在堆上：查看周围的指针，反查分配者
```

**这是唯一能确定来源的方法。** 其他都是猜测。

### 路线 2：**禁用 Juiced 测试**

Juiced 有 `CModLoader=1`、`TagHook=1` 等**运行时字符串改写钩子**，
可能是它在这条字幕上做了某种处理。

```
做法（用户已有一个"只装 Juiced + DLC 不崩"的配置）：
  临时把 Mods/JUICED - Strings 从 loose.txt 里去掉
  或 把 DFEngine.dll 换成原版
  -> 看字幕是否还乱码
风险：可能起不来（需 dgVoodoo）
```

### 路线 3：**接受现状**

```
✓ Juice 菜单英文可读

✓ 拆车厂崩溃已解决
```
